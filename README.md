# p1tiler
A framebuffer-based tiling terminal manager.
IT was made as a challenge for a Pentium 120 MHz, 8 MiB RAM, no SWAP and no X11 or Wayland.

It Features Three workspaces, four terminals per workspace, compressed wallpapers, dynamic resolutions, live configuration.

Requirements/building: Compiler , musl, framebuffer support  
Keyboard shortcuts, configuration options and wallpaper locations.

Limitations: ASCII terminal support, 16-bit RGB555/RGB565 framebuffer, supported resolutions.
